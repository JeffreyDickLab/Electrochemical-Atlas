Electrochemical Atlas

Open the portable application using your operating system's launcher. If you downloaded the GitHub source archive, the compiled launchers are intentionally absent; build them with Go or obtain a portable release asset.

Open the launcher for your system:
Windows: Launch_Electrochemical_Atlas.bat
macOS: Launch_Electrochemical_Atlas.command
Linux: Launch_Electrochemical_Atlas.sh
Keep the application folder together. A first-run portable package may need a one-time internet connection to install the PDF.js renderer. Complete offline releases bundle that dependency.
